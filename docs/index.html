半年の見通し

契約先ごとに、月ごとの売上（税抜・万円）を入れてください。最初は上で入れた金額が毎月続く前提で入っています。決まっていない契約は「見込み」に印を付けます。

2割特例は2026年分で終わる。インボイス登録で課税事業者になった個人なら、2027・2028年分は売上の消費税の3割を納める「3割特例」が使える（届出不要）。

所得税・住民税・個人事業税は、この6か月を2倍した額を1年の収入とみなして計算し、各月のもうけに応じて割り振った「取り分けの目安」です。実際に払う月（確定申告は3月、住民税は6月から）とは違います。社会保険料は年額の12分の1を毎月に置いています。

計算の前提

    使っている数字

    • 健康保険料率：協会けんぽ 令和8年度（令和8年3月分から適用）。介護保険料率 1.62%
    • 子ども・子育て支援金 0.23%（労使折半。令和8年4月分から健康保険料に上乗せ）
    • 厚生年金 18.3%（労使折半）、雇用保険 労働者負担 0.5%（令和8年度・一般の事業）
    • 国民年金 月17,920円（令和8年度）
    • 給与所得控除・基礎控除は令和8年度税制改正後の令和8年分の金額（基礎控除は合計所得489万円以下で104万円、給与所得控除の最低保障は74万円）
    • 扶養親族・配偶者控除の所得要件は62万円以下（給与だけなら年収136万円以下）

    できないこと

    • 生命保険料控除・地震保険料控除・医療費控除・住宅ローン控除・ふるさと納税は入っていない。該当すれば実際の手取りはこれより増える
    • 住民税の調整控除を入れていないため、住民税が数千円多めに出る
    • 社会保険料は年収÷12を毎月の報酬とみなして標準報酬月額の等級に当てはめた額。賞与や残業による月ごとの変動は見ていない
    • 19〜22歳の家族は特定扶養控除のみ（特定親族特別控除は未対応）
    • 国民健康保険の概算には子ども・子育て支援金分を入れていない（率が市区町村ごとに違うため）
