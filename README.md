# 手取り教えタロウ

会社員・副業・フリーランスの手取りを月額で計算する無料ツール。

**https://shutsumi.github.io/tedori-taro/**

額面や売上から、社会保険料・所得税・住民税・個人事業税・消費税を引いて、
手元に残る金額を出します。

## できること

- 働き方を「会社員」「会社員と副業」「フリーランス」から選ぶ
- 業務委託は取引先ごとに複数入力できる（追加・削除可）
- 月額でも年額でも入力でき、切り替えると金額も換算される
- 47都道府県ごとの健康保険料率
- 配偶者控除・配偶者特別控除・扶養控除（一般／特定／老人）
- 年収の壁（123万・130万・160万）を目盛りで表示
- 消費税の扱いを5通りから選択（免税／請求なし／2割特例／簡易課税／本則）
- 青色申告特別控除、iDeCo、小規模企業共済
- 住民税の翌年課税（独立・転職1年目のずれ）
- 入力はブラウザに保存され、再読み込みしても消えない

## 使っている数字（令和8年度）

| 項目 | 値 |
|---|---|
| 健康保険料率 | 協会けんぽ 47都道府県（令和8年3月分から適用） |
| 介護保険料率 | 1.62%（40歳以上65歳未満） |
| 厚生年金 | 18.3%（労使折半） |
| 雇用保険 | 労働者負担 0.5%（一般の事業） |
| 国民年金 | 月17,920円 |
| 給与所得控除・基礎控除 | 令和7年度税制改正後 |

## 入っていないもの

生命保険料控除・地震保険料控除・医療費控除・住宅ローン控除・ふるさと納税、
住民税の調整控除、標準報酬月額の等級区分、特定親族特別控除。
国民健康保険は自治体差が大きいため概算（金額を直接入力して上書きできる）。

**概算を出すための道具です。税額の確定や申告の判断は税務署・税理士に確認してください。**

## 作り

単一のHTMLファイル。フレームワークもビルドツールも使っていない。

| ファイル | 役割 |
|---|---|
| `index.html` | 中身。`<head>` を持たない断片 |
| `build.py` | `index.html` に `<head>` を付けて `docs/index.html` を出力する |
| `docs/` | GitHub Pages が配信するディレクトリ |

`index.html` を直したら、必ず `python3 build.py` を実行してから push する。

```bash
python3 build.py
```

公開設定は GitHub Pages（`main` ブランチの `/docs`）。
